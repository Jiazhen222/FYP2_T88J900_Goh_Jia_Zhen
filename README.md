# IOT-based Indoor Air Quality Monitoring and Alert System (Phase 1)
This repository contains the software validation, algorithm training, and optimization assets for Phase 1 of the IAQ research project.
## Hardware Environment
- Central Hub: Raspberry Pi 4B
- Sensor Nodes: ESP32
- Development OS: Linux Mint 22

## Developed Models
- Hybrid LSTM (Temporal Forecasting)
- Random Forest (Categorical Classification)
- GRU and Quantile Mapping Baselines

All models are optimized in .tflite format for edge deployment.
